# Sistem Katalog Produk Cookies Berbasis Web

Aplikasi web sederhana berbasis PHP dan MySQL untuk mengelola katalog produk cookies menggunakan konsep CRUD.

## Fitur
- Tambah produk
- Tampilkan produk
- Edit produk
- Hapus produk
- Sorting data produk

## Teknologi
- PHP Native
- MySQL (phpMyAdmin)
- HTML

## Struktur Database
Database: katalog_cookies  
Tabel: produk

## Cara Menjalankan
1. Simpan folder di `htdocs`
2. Jalankan Apache & MySQL (XAMPP)
3. Import database
4. Akses melalui browser:
   - http://localhost/cookies_crud/tampilProduk.php
